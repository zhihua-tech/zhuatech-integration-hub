# 企业集成平台企业能力

## 领域覆盖

- **连接器管理**：配置数据库、API、消息、文件和SaaS连接器及凭据引用
- **接口契约**：维护协议、Schema、版本、负责人和兼容性策略
- **数据映射**：设计字段转换、代码映射、脱敏、校验和默认值
- **集成流程**：编排来源、转换、路由、聚合、分支和目标节点
- **调度与触发**：支持定时、事件、Webhook和人工补数触发
- **可靠性控制**：提供幂等、重试、超时、熔断和流量保护
- **死信处理**：归集失败消息、分派原因、修复并安全重放
- **运行可观测**：跟踪吞吐、成功率、延迟、积压、链路和告警
- **发布与审计**：执行环境推广、变更审批、回滚和操作审计

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业集成平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `API_GATEWAY`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
